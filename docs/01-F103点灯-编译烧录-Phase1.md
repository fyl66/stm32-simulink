# 阶段 1：F103C8T6 点灯（生成 → 编译 → 烧录 → 运行）

目标：用 Simulink 模型驱动 STM32F103C8T6 的 6 个 GPIO，实现一键 `Ctrl+B` 编译并烧录运行。

---

## 1. 硬件接线

| 信号 | MCU 引脚 | 说明 |
|---|---|---|
| SWDIO | PA13 | ST-LINK SWDIO |
| SWCLK | PA14 | ST-LINK SWCLK |
| GND / 3V3 | — | 共地、供电 |
| LED0~LED4 | PA0 PA1 PA2 PA3 PA4 | 阳极接 3V3，阴极接 IO → **低电平点亮** |
| LED5 | PC13 | 同上 |

> **注意**：LED 应串限流电阻（330Ω~1kΩ），否则可能超过 GPIO 灌电流。

---

## 2. 生成 CubeMX 工程 `.ioc`

可用 CubeMX GUI，或用脚本生成基线后修改：

```matlab
run('E:\stm32_simulink\scripts\stm32_create_ioc.m')   % 生成 00_HW/F103C8T6/F103C8T6.ioc
```

`.ioc` 关键配置（`00_HW/F103C8T6/F103C8T6.ioc`）：

| 项 | 值 |
|---|---|
| 器件 | `STM32F103C8Tx`（LQFP48） |
| RCC | HSE 8MHz 晶振 → PLL×9 → SYSCLK **72MHz** |
| SYS Debug | **Serial Wire**（保留 PA13/PA14） |
| **时基源** | **TIM2**（不能是 SysTick） |
| GPIO | PA0-4、PC13 = `GPIO_Output`，Push-Pull，No Pull，初始 High |
| ProjectManager | `NoMain=true`，Toolchain=STM32CubeIDE，FirmwarePackage=`STM32Cube FW_F1 V1.8.6` |

对应片段：

```text
Mcu.Pin10=VP_SYS_VS_tim2
NVIC.TIM2_IRQn=true\:15\:0\:false\:false\:true\:false\:true\:true
NVIC.TimeBase=TIM2_IRQn
NVIC.TimeBaseIP=TIM2
PA0-WKUP.GPIO_ModeDefaultOutputPP=GPIO_MODE_OUTPUT_PP
PA0-WKUP.Signal=GPIO_Output
...
ProjectManager.NoMain=true
ProjectManager.functionlistsort=1-MX_GPIO_Init-GPIO-false-LL-false,2-SystemClock_Config-RCC-false-LL-false
```

校验（CubeMX 加载并回存，`status=0` 即合法）：

```matlab
run('E:\stm32_simulink\scripts\stm32_validate_ioc.m')
```

> 导入时可能出现 `OptionalMessage_ERROR`（如 `RCC.ADCFreqValue` 等派生值、`VP_RIF_VS_RIF1`）——CubeMX 会自行重算，非致命。

## 3. 生成 Simulink 模型

```matlab
run('E:\stm32_simulink\scripts\stm32_create_model.m')
```

模型结构：
- `Digital Port Write`（`stm32blockslib/Digital Port Write`）
  - 块 A：Port=`GPIOA`，PinNumber=`[0 1 2 3 4]`，`ReadOperation=off`，`IOAsArray=on` → 1×5 输入
  - 块 B：Port=`GPIOC`，PinNumber=`[13]`，同上 → 1×1 输入
- `Pulse Generator`：周期 2s、占空比 50% → 驱动 `Mux(5)` 与 GPIOC
- 固定步长 `0.01s`

> 低电平点亮：输入 0 = 亮。方波驱动即可看到约 1Hz 交替。

目标配置（关键）：

```matlab
set_param(m,'HardwareBoard','STM32F1xx Based');
set_param(m,'Toolchain','GNU Tools for STM32');
codertarget.data.setParameterValue(m,'STM32CubeMX.ProjectFile', iocPath);
codertarget.data.setParameterValue(m,'STM32CubeMX.DeviceId',    'STM32F103C8Tx'); % 必须
codertarget.data.setParameterValue(m,'STM32CubeMX.Family',      'STM32F1');       % 必须
codertarget.data.setParameterValue(m,'Runtime.BuildAction',     'Build, load and run');
codertarget.data.setParameterValue(m,'STM32CubeMX.ConnectivityMode','st-link');
codertarget.data.setParameterValue(m,'STM32CubeMX.ConnectionPort','SWD');
codertarget.data.setParameterValue(m,'STM32CubeMX.Frequency',   '4000');
codertarget.data.setParameterValue(m,'STM32CubeMX.Mode',        'Normal');
codertarget.data.setParameterValue(m,'STM32CubeMX.ResetMode',   'Software reset');
codertarget.data.setParameterValue(m,'STM32CubeMX.AutoDetectBoard',1);
```

> **坑**：只设置 `ProjectFile` 不会自动解析 `.ioc`；不写 `DeviceId`/`Family` 会导致烧录前设备检测返回 `No STM32 MCU connected`。

## 4. 构建与烧录

```matlab
cd('E:\stm32_simulink');
slbuild('F103_Blink');
```

后台链路：

```
Simulink 生成 C
  → STM32CubeMX 从 .ioc 生成 HAL 初始化代码
  → GNU arm-none-eabi 编译/链接（生成 .elf/.bin/.hex）
  → STM32CubeProgrammer CLI 经 ST-LINK 擦除/烧录/校验
  → 复位运行
```

成功输出（示例）：

```

      FLASH:      4496 B      64 KB      6.86%

```
