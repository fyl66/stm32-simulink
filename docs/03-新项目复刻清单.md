# 新项目复刻清单（换芯片 / 换板卡）

按顺序执行，可快速把本流程复用到新的 STM32 芯片或板卡。

## A. 环境（一次性，见 `docs/00`）

- [ ] 授权核对：`rtw_embedded_coder` / `real-time_workshop` / `stm32_blockset` 均为 1。
- [ ] 注册工具：`scripts/stm32_register.m`（CubeMX / CubeProgrammer / CubeCLT / 仓库）。
- [ ] 安装对应系列固件包（改 `stm32_install_fw.m` 的系列与版本，版本见
      `toolbox\stm32b\stm32shared\stm32mcuinfo.json`）。
- [ ] 安装并注册 CMSIS：`scripts/stm32_install_cmsis.m`。
- [ ] 工程放在**纯 ASCII 路径**。

## B. 新建硬件工程

- [ ] 复制 `00_HW/<旧MCU>/` → `00_HW/<新MCU>/`，用 CubeMX 打开 `.ioc` 改器件。
- [ ] 配置：
  - [ ] RCC：HSE/HSI 与目标主频。
  - [ ] SYS Debug = **Serial Wire**。
  - [ ] **Timebase Source = 非 SysTick**（如 TIM2）。
  - [ ] 目标外设与 GPIO（与模型块一致）。
  - [ ] `ProjectManager.NoMain=true`，固件包版本正确。
- [ ] `scripts/stm32_validate_ioc.m` 校验（status=0）。

## C. 新建/修改模型

- [ ] 从 `F103_Blink.slx` 复制重命名，替换外设块与引脚。
- [ ] 目标配置：
  - [ ] `HardwareBoard` 选择对应系列（如 `STM32F4xx Based` / `STM32H7xx Based`）。
  - [ ] `Toolchain = GNU Tools for STM32`。
  - [ ] `STM32CubeMX.ProjectFile` 指向新 `.ioc`。
  - [ ] **`STM32CubeMX.DeviceId` 与 `Family` 必须显式设置**。
  - [ ] `Runtime.BuildAction = Build, load and run` 与 st-link 参数。
- [ ] 可用 `scripts/stm32_update_paths.m` 更新路径（改脚本内的文件名/器件）。

## D. 构建

```matlab
cd('<ASCII 工程根>');
slbuild('<模型名>');
```

- [ ] 首次失败看 `%TEMP%\stm32_build_diary.txt`。
- [ ] 若设备检测为空：检查 `DeviceId`/`Family` 与 CubeProgrammer 兼容补丁。

## E. 常见变更点速查

| 变更 | 需要改的位置 |
|---|---|
| 换 MCU 型号 | `.ioc` 器件、模型 `DeviceId`/`Family` |
| 换系列（F1→F4/H7…） | `.ioc`、`HardwareBoard`、固件包、`DeviceId`/`Family`、目标库 |
| 增加外设（ADC/CAN/TIM…） | `.ioc` 配置 + 模型外设块；重新生成 |
| 换 CubeMX 版本 | `stm32_register.m` 路径；必要时回退推荐版本 |
| 换 CubeProgrammer 版本 | 若 ≥2.20，需设备名兼容补丁或回退 2.17.0 |
| 换固件仓库 | `stm32_register.m` + CubeMX `updater.ini` |
| 工程迁移目录 | `stm32_update_paths.m`（必须 ASCII） |

## F. 不要做的事

- 不要提交生成物（`slprj/`、`*_ert_rtw/`、elf/hex、CubeMX 生成的 `Core/`、`Drivers/`）。
- 不要在 `.ioc`/脚本里硬编码本机绝对路径。
- 不要忘记删除无头构建用的临时 `questdlg.m`。
